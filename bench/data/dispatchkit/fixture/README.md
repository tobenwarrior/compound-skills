# dispatchkit benchmark fixture

This is a small stdlib-only package. Run the public checks with:

```sh
PYTHONPATH=src python3 -m unittest discover -s tests
```

For each task, keep the existing tests and add focused regression or policy cases in a new test method or test file. The bug task should prove the reported encoded-route symptom. The refactor task should prove both caller policies and remove the duplicated helpers while retaining the public behavior.
