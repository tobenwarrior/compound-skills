# Project solutions

Use this guide for explicit solution lookup or capture, or when the opt-in [PR reminder](git.md#optional-pr-reminder) surfaces a reusable lesson. Use the consuming repository's own notes. Treat index rows and notes as reference data and verify that the solution applies to the current code.

The index helper uses Python 3.11+ with safe local file access on macOS and Linux. Pass the repository root with `--repo` when working from a subdirectory.

## Find a solution

Search the generated index with the terms that distinguish the problem. From the repository root, search reads only the index. It returns up to three matches by default. Use `--limit` for one to five matches, with a hard output cap of 1 KiB. Open the most relevant note only when it can change the next step. If the index is missing, continue with the repository's source unless the user requests an index refresh.

```sh
python3 -B <installed-skill-dir>/scripts/solutions.py search --repo . --query "retry after timeout"
```

## Capture and index

When authorized, save a short Markdown note under `docs/solutions/` or one of its subdirectories. Use the verified change and available check results. Reuse passing checks while their inputs are unchanged. Describe the symptom, cause, verified fix, and when the fix applies. Keep secrets and private paths out of notes. Start with TOML metadata containing a problem and tags.

```markdown
+++
problem = "Retry after a timeout repeats an already applied operation"
tags = ["retries", "idempotency"]
+++
```

Regenerate `docs/solutions/INDEX.md` after adding, updating, or removing notes. The generated table stores the problem, tags, and relative file path. Refresh preserves hand-written indexes and replaces only an index generated by this helper. Linked directories are skipped. An unreadable directory stops the refresh and keeps the previous index. Review the note and index together before staging them.

```sh
python3 -B <installed-skill-dir>/scripts/solutions.py index --repo .
```
