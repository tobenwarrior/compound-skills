# Code maps

Prefer a fresh, suitable index already provided by the host; do not duplicate its scan or repeat map output. Use focused files and import neighbors to choose source reads; confirm behavior and callers in source/tests. Missing entries prove nothing: coverage is bounded and import links are not a complete call graph. Use native search for reported limits. Skip mapping for activation-only requests, non-code work, and questions answerable from a supplied snippet.

`code_map.py --cache-read-only` reuses fingerprint-validated metadata from an existing cache, parsing missing or changed files in memory without writing or starting a service. `--no-cache` bypasses the cache entirely. For write-authorized tasks, omit both to start or reuse the shared local service. Its index reuses unchanged file metadata and checks additions, edits, and deletions. Changing the query reranks the index without forcing a rebuild; `--refresh` requests one. If service startup fails, the helper reports it and falls back to a bounded local scan.

## Symbol lookup

When the host has no suitable symbol or reference tool, run `python3 -B <installed-skill-dir>/scripts/symbol_lookup.py --repo <repo-root> --symbol <symbol>`. Quote untrusted paths and names for the host shell or pass them as argument vectors. It returns bounded JSON with exact-name outline matches and lexical occurrence locations, without source snippets. Occurrences can include declarations, comments, and strings; they are not resolved semantic references. By default the reference scan covers at most 1,000 files, 256 KiB per file, 8 MiB total, and 3 seconds after model setup; JSON defaults to 12 KiB. Check the reported coverage and limits, then confirm in source. By default it reuses a validated cache read-only without starting the service or writing files; `--no-cache` bypasses it. On platforms without safe no-follow directory-relative opens, occurrence scans fail closed and report the gap.

## Live viewer

Use the [map utility](../../map/SKILL.md) for a visual request. It starts or reuses one loopback service at `http://127.0.0.1:43127/` and opens the registered project. `COMPOUND_MAP_PORT` can select another port. Opening again reuses the index; saved project links restore on demand after restart. It creates no HTML snapshot. Cold indexing runs in the background; the page stays responsive and retains its last map during incremental updates. It does not restructure source code.

Map viewing authorizes local cache and service startup only, without repository edits or onboarding cleanup. The helper's `status` and `stop` subcommands inspect or stop this shared service. It runs until stopped or the machine session ends; the next coding or map request starts it again. It scans only repositories registered by those requests, not every project at login.

Python 3.11+ and Git are required; no added dependency, provider, database, or watcher. Python receives AST outlines; JS/TS receives bounded outlines and local imports, including supported relative tsconfig inheritance, project aliases, and workspace package exports. Go, Rust, Java, C/C++, C#, Ruby, PHP, Swift, and Kotlin receive bounded heuristic declaration outlines without import resolution; their first 256 Ki characters are examined and limits are disclosed. Other recognized files have metadata only. These are not language servers: computed imports, cross-language references, and call hierarchies require native search. Git-listed `build/` and `dist/` source is included. Each pass reads at most 64 MiB and 1 MiB per file; beyond those limits, metadata remains visible with partial-outline coverage. The service indexes up to 20,000 files, projects up to 5,000 per response, and draws up to 20,000 links. Search ranks against the larger index; counts distinguish indexed files from the current view. Neighborhoods, impact, and import traces are limited to that view. Import traversal indicates structural relationships, not runtime calls. Normal exclusions appear under coverage; failures and limits remain warnings.

Metadata includes line counts, export hints, unresolved imports, Git changes, and bounded recent co-change history. Rank by the task, dependency importance, and current work; confirm those hints in source. Outlines retain up to 512 symbols per file and disclose truncation. Agent text prioritizes symbols matching the task, defaults to a 2,500-character cap, and is rendered by the service without transferring the full index; `--max-chars` can adjust the limit within the supported bounds.

Metadata and service state stay in Compound's user cache, outside the repository. Normal APIs contain no source bodies. Explicit **Source** or symbol selection reads a bounded 64 KiB preview of an indexed file without caching its body. The loopback service validates indexed paths and rejects private files, traversal, symlinks, and foreign origins. Keep generated maps out of commits; chat summaries enter normal context.
